# Subjective test
This test script is designed for the subjective quality assessment of the models integrated within IVSR. It automatically processes each video from the designated test video folder, utilizing models to generate MP4 videos with `qp=0` for lossless encoding. 

The enhanced videos are saved in the specified folder. It is recommended to use the `VQA`(VQ Analyzer) tool to conduct a comparative analysis of the subjective quality between the processed videos and the original ones.
